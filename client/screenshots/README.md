# Screenshots for Chrome Web Store Listing

Place your screenshots in this directory.

## Requirements

1. **Promotional tile images**:

   - Small tile: 440x280 pixels
   - Large tile: 920x680 pixels

2. **Screenshots**:

   - Must be 1280x800 pixels or smaller
   - Minimum of 1, maximum of 5
   - Show the main functionality of your extension

3. **Other images**:
   - Icon: 128x128 pixels (already included in icons directory)

## Tips for Good Screenshots

1. Show the main functionality of the extension
2. Include text overlays explaining features
3. Keep it clean and focused
4. Use high-quality images
5. Show how the extension integrates with LeetCode
