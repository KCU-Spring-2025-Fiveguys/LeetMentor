# LeetMentor Chrome Extension

LeetMentor is an AI-powered coding companion for LeetCode practice that helps you improve your problem-solving skills by providing hints, code improvements, and follow-up questions.

## Features

- **Instant Hints**: Get hints when you're stuck on a LeetCode problem
- **Code Improvements**: Receive suggestions to optimize your accepted solutions
- **Follow-up Questions**: Learn related concepts after solving a problem
- **History Tracking**: Save and review your learning progress
- **Practice Reminders**: Schedule reminders for consistent practice

## Permissions Explanation

This extension requires the following permissions:

- **activeTab**: To interact with the current LeetCode problem page
- **scripting**: To inject content scripts that extract code from the editor
- **storage**: To save your preferences and feedback history locally
- **alarms**: To schedule practice reminders
- **notifications**: To display reminder notifications
- **sidePanel**: To display your feedback history
- **tabs**: To determine the current tab's URL

## Data Usage

- Your code is sent to our server (leetmentor.vercel.app) only when you request hints or improvements
- All feedback history is stored locally in your browser
- No personal data is collected or stored on our servers
- Practice reminder settings are stored locally
